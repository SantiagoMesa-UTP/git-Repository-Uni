# Kotlin Beginner Workshop

Estudiante: Santiago Mesa

Taller de introducción a Kotlin con ocho ejercicios sobre condicionales, ciclos, colecciones, funciones, clases y manejo de valores nulos.


## Cómo ejecutar

1. Abrir la carpeta KotlinWorkshop en IntelliJ IDEA (con un JDK configurado).
2. Abrir el Main.kt del ejercicio que se quiere correr.
3. Pulsar el botón verde de ejecución junto a fun main().
